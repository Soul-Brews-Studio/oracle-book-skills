## Lessons Learned

1. **รู้ blast radius ก่อนเขียน ไม่ใช่ก่อน publish** — เช็ค public/private ของปลายทาง
   *ตั้งแต่ก่อนพิมพ์เนื้อหาที่มาจากช่องทางส่วนตัว* security scan ก่อน commit เป็นตาข่ายสุดท้าย ไม่ใช่ด่านแรก

2. **ตัวแปร environment ที่ตั้งชื่ออะไรไว้ ไม่ใช่หลักฐานว่าสิ่งนั้นคือตัวตน** — ชื่อ token ≠ ชื่อ oracle ≠ ชื่อ repo
   verify ว่า referent มีจริงและตรงกันก่อนประกาศ

3. **เมื่อ wrapper แปลงคำสั่งให้ ต้องเทียบ output กับค่าที่รู้คำตอบอยู่แล้วก่อนเชื่อ** —
   `wc -l` คืน 0 บนไฟล์ที่เพิ่งเห็นว่า 299KB คือสัญญาณว่า wrapper พัง ไม่ใช่ไฟล์ว่าง

4. **ถ่อมตัวเกินจริง = record ผิด พอๆ กับโอ้อวด** — เป้าหมายของ retro คือความแม่น ไม่ใช่มารยาท

5. **เจอบั๊กในเครื่องมือที่กำลังใช้ ให้รายงานขึ้นต้นน้ำ** — หลบเงียบแก้ให้ตัวเอง 1 ตัว รายงานแก้ให้ทั้งฟลีต
